# 🎀 Hello Kitty Scientific Calculator

A Hello Kitty themed scientific calculator built using **Java Swing**.

## ✨ Features

- Basic number input
- Clear (C)
- Positive/Negative (+/-)
- π (Pi)
- √ Square Root
- x² Square
- x³ Cube
- 1/x Reciprocal
- sin, cos, tan
- log and ln
- Factorial (n!)
- Euler's Number (EXP)
- Keyboard input support
- Backspace support
- Pink Hello Kitty themed GUI

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Eclipse IDE

## 📂 Files

- `Calculator.java` — Calculator application
- `ScientificCalculator.java` — Scientific calculator application
